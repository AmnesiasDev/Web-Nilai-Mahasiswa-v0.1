## Menjalankan di komputer

Pastikan Node.js sudah terpasang, kemudian buka terminal di folder proyek:

```bash
npm install
npm run dev
```

Buka alamat lokal yang ditampilkan oleh Vite.

## Build produksi

```bash
npm run build
```

Hasil build berada di folder `dist`.

## Upload ke Vercel

1. Upload seluruh proyek ini ke repository GitHub.
2. Masuk ke Vercel menggunakan akun GitHub.
3. Pilih **Add New > Project**.
4. Import repository proyek.
5. Klik **Deploy**. Vercel biasanya mendeteksi Vite secara otomatis.

## Peringatan keamanan

Ini adalah proyek latihan. NPM, password, dan nilai masih tersimpan di kode front-end sehingga dapat dilihat melalui browser. Jangan gunakan data asli. Untuk penggunaan sungguhan, pindahkan autentikasi serta data ke backend dan database.
